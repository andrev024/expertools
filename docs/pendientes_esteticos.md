# Pendientes esteticos

Lista de mejoras visuales y de experiencia de usuario que pueden abordarse en futuras iteraciones:

- Revisar consistencia de espaciados, tipografia y jerarquia visual entre paneles.
- Completar estados de carga, vacio y error en las vistas con datos remotos.
- Mejorar la experiencia responsive de tablas y formularios en pantallas pequenas.
- Revisar contraste, foco visible y navegacion por teclado.
- Unificar mensajes de confirmacion y errores de las operaciones principales.
- Evaluar recibos imprimibles para ingreso y entrega de articulos.
